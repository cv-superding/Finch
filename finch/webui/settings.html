04自动续做
续传只恢复原会话；补做会根据验收出的缺漏生成新指令。
自动补做回复结束后识别未完成项与问题，并自动生成补做提示词。
补做前人工确认补做提示词生成后先暂停，可在任务详情中编辑、下发或跳过。
补做提示词先经过优化调用 prompt-optimizer 或内置优化模型后再下发，会增加耗时。
续传指令先经过优化中断续传前先优化续传指令模板，再回到原会话继续。
续传指令模板
补做指令模板
可用占位符：{task} 原任务、{summary} 摘要、{items} 缺漏与问题、{title} 标题。
05结果解析
优先调用 OpenAI 兼容接口做语义提取；未启用或调用失败时自动回退到关键词/正则规则。
启用大模型语义解析需要填写 Base URL、API Key 与模型名。密钥仅保存在本机。
结果解析模型仅用于解析结果，不会写入任务日志。
API Key密钥仅保存在本机，不会上传。
模型建议使用支持 JSON 输出的指令模型。
识别偏好 会附加到解析提示词中；人工修正也会作为示例自动参考。
连接检查发送一条最小请求验证配置。
06提示词优化
调用 prompt-optimizer MCP（推荐 Docker 部署）或内置优化模型，支持用户提示词与系统提示词。
优化方式「优化提示词」按钮与自动补做优化共用此设置。
MCP 地址prompt-optimizer Docker 默认 http://localhost:8081/mcp
优化模板对应 prompt-optimizer 的模板 ID，留空使用默认。
使用独立的优化模型关闭时复用上方「结果解析模型」配置。
优化 Base URL独立优化模型的接口地址。
优化 API Key仅保存在本机。
优化模型留空时使用解析模型。
MCP 连接检查验证服务与 optimize-user/system-prompt 工具是否可用。
